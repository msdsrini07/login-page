
---

## 🔐 Login Flow

```text
Username
    ↓
Password
    ↓
   Login
    ↓
login.php
    ↓
Backend Authentication
```

The current project is primarily a **frontend UI**. Real authentication requires a backend such as **PHP + MySQL**.
